# Event Booking Website

## How to run the application

1. npm install

2. npm run build-db

3. npm run start

4. Open the website at:

http://localhost:3000/

## About the application

This is an event booking website. The organiser can create, edit, publish and delete events. The organiser can also change the website name and description. Attendees can view published events and book tickets.

## Additional libraries

- Express
- EJS
- SQLite3
